GLOBAL RULES (STRICT)

Logos

All logo references must use assets from:

/destinychurch/Logos


Use the correct logo in the correct place:

Full horizontal logo → headers, footers

Icon-only logo → must be inside a white or light-grey circular background

No recolouring

No overlaying icon on wordmark

Fonts

All fonts must be loaded from Google Fonts

No self-hosted fonts unless unavoidable

Icons

Use Google Fonts Icons only

Material Symbols / Material Icons

No third-party icon libraries

Database

No database is used initially

Use local JSON / TypeScript data files

Architecture must allow adding Supabase (or similar) later without refactor

PROJECT OVERVIEW

Project Name: Destiny Church Website

Primary Domain: destinytees.uk

Tech Stack:

Next.js (App Router)

TypeScript

Tailwind CSS

Vercel

External APIs (server-side only):

Google YouTube Data API v3

OpenAI API (Whisper + GPT)

1) CORE PURPOSE

This project builds the entire Destiny Church Tees Valley website.

The website must:

Serve as the primary digital front door for the church

Clearly communicate:

What Destiny Church is

When and where services happen

How people can get involved

Feel modern, welcoming, and confident

Work beautifully on mobile first

Key Principle

Destiny Sermons is a feature, not the platform.
It lives inside the site as /watch and /sermons, sharing the same design system, navigation, and branding.

2) DESIGN INSPIRATION & TONE

6) SERMONS FEATURE (DESTINY SERMONS)
Functionality

Pull YouTube Live replays using YouTube Data API

Pull sermon-only podcast episodes via RSS

Attempt to match podcast + YouTube by date

Admin approval via secure email link

Once approved:

Podcast audio → Whisper → transcript

Transcript → GPT → summary

Saved locally (file-based initially)

Visitor Experience

YouTube-style sermon grid

Individual watch page with:

Embedded video

Summary

Collapsible transcript

Recommended sermons

7) LOCAL “CONTINUE WATCHING” (NO ACCOUNTS)

Uses localStorage

Device-only

No authentication

Storage key:

destiny-sermons-progress


Removes progress automatically when sermon is finished.

8) OPENAI INTEGRATION
Whisper

Input: podcast audio

Output: full transcript

GPT Summary

Warm, Christ-centred tone

3–6 bullet points

Key scripture references

Destiny pastoral voice

9) YOUTUBE API USAGE

https://www.googleapis.com/youtube/v3/search


Parameters:

channelId

eventType=completed

order=date

type=video

part=snippet
