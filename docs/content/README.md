# Source copy

Long-form text supplied by the church or by partner organisations, kept here as
the reference copy. The live pages render an edited subset of it — e.g.
`app/privacy/page.tsx` carries roughly a fifth of `privacy-policy.txt` — so these
files are the fuller source, not a stale duplicate. Check here before rewriting
policy or partner wording.

| File | Used by |

| `terms-of-use.txt` | `/terms` |
| `compassion.txt` | `/missions` — partner description |
| `safe-families.txt` | `/missions` — partner description |
