Project Name: Destiny Sermons
Domain: sermons.destinytees.uk
Tech Stack: Next.js (App Router) + TypeScript + Tailwind CSS + Vercel + Supabase (or similar DB)
External APIs:

Google YouTube Data API v3

OpenAI API (Whisper + GPT)

Purpose:
A dedicated platform for Destiny Church that automatically collects weekly sermons (YouTube Live + Podcast), generates AI summaries and transcripts, and provides a clean, modern, YouTube-like browsing experience.
The site includes local device-based Continue Watching, but NO user accounts.

=====================
1. CORE PURPOSE
=====================

The platform:

Pulls YouTube Live replays from the Destiny Church YouTube channel using Google YouTube Data API.

Pulls sermon-only podcast episodes from an RSS feed.

Suggests a match between podcast + live video based on upload date.

Sends an admin email allowing approval of the match.

Once approved:

Downloads podcast audio

Sends audio to OpenAI Whisper → transcript

Sends transcript to OpenAI GPT → summary

Saves everything to DB

Visitors can:

Browse sermons using a YouTube-like grid

Click into a watch page

View the video, summary, transcript

Use local-only continue watching stored via browser storage

The UI must feel similar to YouTube while maintaining full Destiny Church branding.

4. LOCAL CONTINUE WATCHING (NO ACCOUNTS)
=====================

A localStorage-based continue watching system that works ONLY on the visitor’s device.
No Firebase, no login, no external authentication.

4.1 Storage Key

destiny-sermons-progress

4.2 Stored Structure Example
[
  {
    sermonId: "2025-12-07-am",
    lastPosition: 623,        // seconds
    lastUpdated: 1733608000   // timestamp
  }
]

4.3 Behavior

When the user pauses, seeks, or navigates away, update localStorage with the timestamp.

On the homepage, show a “Continue Watching” row if any progress exists on that device.

If the user finishes the video (e.g., within 30 seconds of the end), automatically remove the entry.

Continue Watching is device-specific only.

4.4 Hook Implementation

A custom React hook should handle:

Reading progress

Writing progress

Clearing progress

Returning sorted items by lastUpdated

=====================
5. DATA FLOW AUTOMATION
=====================
5.1 Cron Job (Vercel Cron) – /api/sermon-sync

Runs daily or hourly.

Responsibilities:

Fetch RSS feed

Fetch YouTube Live completed videos

Identify new items

Attempt to match podcast ↔ YouTube based on date

Create match suggestion if found

Send admin email

Clicking the link triggers:

GPT summary generation
