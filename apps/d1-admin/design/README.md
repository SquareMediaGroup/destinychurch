# Design files

Claude Design exports, kept here as the reference for D1 Admin. Open either
`.html` in a browser (they unpack themselves, no server needed).

- `the-one-app-mac.html` - "The One App - Mac": the canvas D1 Admin is built
  from. Two boards: the app (sign in, chat, search, inspector, reports,
  access requests, paused groups, people, audit log, sheets) and the menu bar
  with notifications.
- `destiny-one-messaging-app-design.html` - the Destiny One messaging app
  design (the phone app's chat). Reference for message, reaction and
  composer behaviour that the Mac app should match.
